# Student Management REST API

A backend REST API for managing student information using Node.js, Express.js, MongoDB Atlas, and Mongoose.

## 🚀 Project Description

This project is an extension of the Student Management API from Task 3.

In Task 3, student data was stored in an in-memory array. In this project, the data is stored permanently in MongoDB Atlas.

The API supports CRUD operations:

- Create students
- Read students
- Update students
- Delete students

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- dotenv
- Postman
